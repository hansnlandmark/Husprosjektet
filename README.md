# Husprosjektet

En enkel, norsk app for å planlegge oppussing og tegne plantegninger.

## Første versjon

- Legg til stue, kjøkken, soverom, bad, gang og andre rom.
- Flytt rom på tegneflaten ved å dra dem.
- Endre navn, bredde, lengde og farge.
- Se beregnet areal per rom.
- Automatisk lokal lagring i nettleseren.
- Eksporter og importer prosjektet som JSON.

## Kom i gang

Åpne `index.html` i en nettleser. Appen krever ingen installasjon eller server.

## Videre utvikling

Planlagte utvidelser:
- Vegger, dører og vinduer med nøyaktige mål.
- Flere etasjer og rom som kan kobles sammen.
- Materialer, farger og møbler.
- 3D-visning og lagring/synkronisering på tvers av enheter.

## Lagring

Denne første versjonen lagrer automatisk i nettleseren på enheten du bruker. Bruk «Eksporter prosjekt» for å ta vare på en sikkerhetskopi eller flytte prosjektet til en annen enhet.
